КУХНИ МИРА — исправленный HTML/CSS-макет

Файлы:
- index.html — экран входа
- admin.html — макет административной панели
- styles.css — оформление и адаптивность

Запуск:
Откройте index.html в браузере. Для просмотра макета панели можно открыть admin.html.

Важно:
Это только статическая HTML/CSS-верстка. В ней нет PHP, JavaScript, MySQL,
реальной авторизации, CRUD, работающих фильтров/сортировки/пагинации,
обработки изображений, водяных знаков и REST API.

Ограничения HTML:
Атрибуты required, minlength, maxlength, min и accept обеспечивают лишь
браузерную базовую проверку. Ограничение количества файлов, размера,
разрешения, уникальности значений, проверка роли и все бизнес-правила
должны повторно проверяться на сервере.

Вёрстка отражает структуру и поля, перечисленные в модуле Б конкурсного
задания. Демонстрационные данные в таблицах условные.
